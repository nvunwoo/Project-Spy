# PROJECT SPY

1vs1 동시 명령 첩보 전략 게임

### [테스트 플레이](https://nvunwoo.github.io/Project-Spy)


> 이 페이지는 브라우저 한 대에서 실행되는 **fixture 기반 로컬 훈련판**입니다.   
> 지도에서 명단 은닉 위치를 선택하고 일반·배신자 명령을 입력한 뒤 3D 수행과 결과를 볼 수 있습니다.   
> RED는 결정적 연습 상대입니다. 실제 1대1 온라인 대전, 서버 저장, 계정, Supabase 연동은 없습니다.   
> 정적 사이트이므로 브라우저에 연습용 판정 데이터가 포함되며 비밀 정보를 보호하는 실전 서버의 대체물이 아닙니다.
