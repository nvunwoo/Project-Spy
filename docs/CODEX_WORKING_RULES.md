# 보관 상태의 작업 규칙

2026-09-25 정리 지시에 따라 이 저장소는 main 한 브랜치에 소스·기획·맵·테스트를 보관하고 GitHub Pages로 로컬 훈련판을 제공합니다. **추가 개발 예정은 없습니다.** 이전 Phase 0B 개발·Preview·Production 전달 규칙 원문은 [보존본](archive/2026-09-25/CODEX_WORKING_RULES_phase0b5.md)에 있습니다.

1. 작업 전 [현재 상태](CURRENT_STAGE.md)와 [문서 지도](README.md)를 읽습니다. 게임 규칙은 여섯 v0.7 문서가 소유합니다.
2. TBD인 최종 이름·세계관·아트나 새 규칙·숫자를 임의로 정하지 않습니다.
3. GitHub Pages는 공개 정적 연습판입니다. 브라우저 번들에는 로컬 fixture가 포함되며 실전 비밀 정보 보안의 증거로 사용하지 않습니다.
4. 미래 실전판은 서버가 턴·난수·이동·정보·경제·승패를 판정하고 플레이어별 투영만 반환해야 합니다.
5. 비밀키, 토큰, DB 비밀번호, 실제 .env 파일, 공급자 연결 파일은 소스·문서·로그·커밋에 기록하지 않습니다. .env.example만 이름과 비민감 예시를 담습니다.
6. 검증 결과는 정적 검사, 단위 테스트, 빌드, 브라우저, 두 클라이언트, 실기기, 배포로 나눠 정확히 적습니다.
7. 향후 개발은 새 사용자 지시로만 시작하며, [재개 계획](production/FUTURE_DEVELOPMENT_PLAN.md)을 현재 일정으로 취급하지 않습니다.
